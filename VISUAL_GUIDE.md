## 📏 Spacing & Sizing

### Section Spacing:
```
Vertical padding: 2rem (32px)
Between sections: 0 (sections touch)

┏━━━━━━━━━━━━━━━━┓
┃ Section 1      ┃ ← 32px padding top
┃ Content...     ┃
┃                ┃ ← 32px padding bottom
┣━━━━━━━━━━━━━━━━┫ ← No gap
┃ Section 2      ┃ ← 32px padding top
┃ Content...     ┃
```

### Card Sizing:

**Featured Categories:**
- Desktop: 80x80px images, 6 columns
- Tablet: 80x80px images, 4 columns
- Mobile: 64x64px images, 2 columns

**Service Cards:**
- Desktop: 5 columns, ~200px wide each
- Tablet: 3 columns
- Mobile: 2 columns

## 🎯 Key Visual Indicators

### Wholesale Theme Active:

**✅ Checklist:**
```
□ Black bar at very top
□ Wholesale tagline visible (desktop)
□ Centered search bar (desktop)
□ Colored navigation bar
□ Category grid after slider
□ Service cards present
□ Scrolling stats bar
□ Dark footer (black)
□ White footer text
□ Smooth hover animations
```

### Responsive Breakpoints:

```
Mobile:   < 576px   (2-column layouts)
Tablet:   576-991px (3-4 column layouts)
Desktop:  992px+    (5-6 column layouts, full features)
```

## 🔄 Animations

### 1. **Stats Bar Scroll:**
```
Speed: 40 seconds for full loop
Direction: Right to left ←
Type: Continuous, seamless
```

### 2. **Card Hover:**
```
Transform: translateY(-2px to -3px)
Duration: 0.2s - 0.25s
Easing: ease
```

### 3. **Image Zoom:**
```
Transform: scale(1.05)
Duration: 0.3s
Easing: ease
Target: Category/product images on hover
```

## 🎭 Typography

```
Headings:
H1: clamp(1.75rem, 3vw, 2.5rem)   - Page titles
H2: clamp(1.5rem, 3vw, 2rem)      - Section headings
H3: clamp(1.25rem, 2vw, 1.75rem)  - Sub-headings

Body:
Regular: 0.875rem - 1rem          - General text
Small: 0.75rem - 0.8rem           - Card descriptions, labels
Tiny: 0.7rem                      - Footer links, utility bar

Weight:
Bold: 600                         - Headings, important text
Medium: 500                       - Card titles, navigation
Normal: 400                       - Body text
```

## 🖼️ Image Guidelines

### Category Images:
- **Size:** Minimum 200x200px (recommend 400x400px)
- **Format:** JPG or WebP
- **Aspect Ratio:** 1:1 (square)
- **Background:** White or transparent
- **Style:** Product on clean background

### Hero Slider:
- **Desktop:** 1920x600px
- **Tablet:** 1024x480px
- **Mobile:** 768x480px
- **Format:** JPG or WebP
- **Content:** Wholesale-focused messaging
